## Промпт 1: генерация ключей для поиска картинок

Тема статьи: «$article_title»
Подбери для нее 10 одно-двух сложных ключей на АНГЛИЙСКОМ ЯЗЫКЕ для поиска картинок в стоковых базах (Unsplash, Pixabay). Ключи должны полностью описывать тему, дополнять статью и не дублироваться.
Пример:
Тема статьи: «Озеро Байкал где находится 🌊 Глубина, координаты и факты»
Ключи: lake baikal, baikal winter, baikal summer, baikal olkhon, baikal seal, baikal nature, baikal map, baikal ice, baikal coast, baikal russia

Верни ТОЛЬКО JSON-массив строк без комментариев: ["key1", "key2", ...]

## Промпт 2: батч-перевод запросов (используется тем же агентом)

Переведи следующие поисковые запросы для поиска картинок на английский. Сохрани краткость и ключевые слова, не добавляй ничего лишнего. Верни ТОЛЬКО JSON-объект {оригинал: перевод} без комментариев.

Запросы:
$queries_list
