### UI — большая задача: рефакторинг навигации

Цель: убрать запутанную систему кнопок «Назад / + Новая / К форме / К генерации» и заменить чёткой структурой.

**Структура:**
- Боковая панель слева — **всегда видна**: 🏠 Главная / ✍️ Написание / ✅ Результат (потом + Публикация).
- Верхняя плашка справа — **только на Главной**: Сайты / Аналитика / История статей.
- На Главной — форма создания статьи (как сейчас).
- Шаги переключаются кликом по боковой панели. Активная генерация **не прерывается** при переходе на другой шаг — отображается индикатором в боковой панели.
- Авто-переход на «Результат» после завершения пайплайна.
- На пустых шагах — заглушки («активной генерации нет», «результата пока нет»).
- Во время активной генерации на «Результат» — «генерация в процессе, придём автоматически».

**Что удалить:**

**Что оставить:**

- Действующие кнопки на страницах (+ Создать сайт, + Добавить автора) — остаются.

**Этапы реализации:**
1. Layout: боковая панель + сетка.
2. Функция showStep(name) + маркер активного шага.
3. Заглушки для пустых шагов.

### Большая задача: миграция на веб (FastAPI + Docker)

**Цель:** убрать GUI на PySide6/QtWebEngine, перевести приложение на FastAPI-бэкенд + браузерный фронтенд. Позволит запускать локально через браузер и потом задеплоить на сервер для доступа с любого устройства.

**Стек:**
- Backend: FastAPI, существующий PostgreSQL, Celery + Redis для пайплайна, WebSocket для realtime
- Frontend: HTML/CSS/JS (можно переиспользовать ~80% существующего из main_window.py)
- Аутентификация: basic auth с одним юзером в .env
- Docker: два контейнера (frontend, backend) + postgres + redis в docker-compose

**Этапы (каждый — отдельная сессия):**

1. **Этап А — фундамент.** Поднять FastAPI рядом с существующим Qt-приложением. 2-3 простых endpoint'а (`/api/sites`, `/api/articles`). Браузер на `localhost:8000` показывает базовые списки. Qt продолжает работать параллельно.

2. **Этап Б — форма + пайплайн.** Перенести форму создания статьи. Запуск пайплайна через Celery + Redis. WebSocket для логов и статуса. Параллельно с Qt.

3. **Этап В — остальные страницы.** Sites, Analytics, History, Result, review-панель архетипов.

4. **Этап Г — удалить Qt.** Убираем PySide6, run.py запускает только FastAPI.

5. **Этап Д — Docker.** docker-compose.yml с frontend/backend/postgres/redis. Запуск одной командой.

6. **Этап Е — деплой.** На реальный сервер с доменом.

**Зачем:** работать с телефона, проще обновлять, проще админить.
