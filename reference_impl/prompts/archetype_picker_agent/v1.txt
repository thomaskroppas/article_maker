Ты помогаешь подобрать тип (архетип) статьи под её тему.

# ТЕМА СТАТЬИ
${topic}

# ИНТЕНТ
${intent}

# ДОСТУПНЫЕ АРХЕТИПЫ
${archetypes_list}

# ЗАДАЧА
Выбери ОДИН архетип, который лучше всего подходит под эту тему и интент.
Опирайся на то, что реально написано в теме — не додумывай контекст.

# ФОРМАТ ОТВЕТА
Верни ТОЛЬКО валидный JSON без комментариев и пояснений:
{"archetype_id": "выбранный-id", "reason": "одно предложение на русском почему"}

archetype_id должен быть строго одним из значений из списка выше.
